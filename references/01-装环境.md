# 第 1 步：装环境

## 要装什么

| 东西 | 干什么用 | 装在哪 |
|---|---|---|
| Python 3.9 以上 | 跑所有脚本 | 系统里已有的，或 python.org / winget 装的 |
| ffmpeg | 读写视频、混音 | Mac：Homebrew；Windows：winget（Gyan.FFmpeg） |
| Python 包 | numpy、scipy、pillow、skia-python（画画面）、pyloudnorm（响度）、openpyxl（表格）、yt-dlp（下官方素材），转写用 mlx-whisper（苹果芯片）或 faster-whisper（其他） | 当前 Python 已经全有就直接用，否则建专用环境 `~/.bruce-ai-jianji/venv` |
| 字体 | 小赖、站酷快乐体、思源黑体、Nunito 等，全是可商用开源字体 | `~/.bruce-ai-jianji/fonts`，第一次画画面时自动下载 |
| 转写模型 | whisper-large-v3-turbo，约 1.5 GB | `~/.cache/huggingface` |

不需要 Node.js，不需要 Chrome。

## 怎么做

1. 先只检查：
   ```
   python3 <技能>/scripts/check_env.py          # Windows: py <技能>\scripts\check_env.py
   ```
   打印一张表，每行一个东西：✓ 有、✗ 缺。最后一行 `PYTHON=<路径>`。
2. 全是 ✓：记下 `PYTHON=` 后面的路径，之后所有脚本都用它跑，直接进第 2 步。
3. 有 ✗：告诉用户「缺 X 和 Y，我来装，大概要 N 分钟」，然后：
   ```
   python3 <技能>/scripts/check_env.py --install
   ```
   跑完再看一遍表。下载模型最慢，可以用 `run_in_background` 跑，同时做第 2 步（建工程、等用户放文件）。
   用户只想先看看流程、暂时不转写：加 `--no-model`，第 5 步之前再装模型。

## 要用户动手的情况

| 情况 | 跟用户说 |
|---|---|
| Mac 没有 Homebrew | 脚本会打印安装命令。告诉用户：「复制这行到『终端』里运行，中间要输一次开机密码（输的时候屏幕上不显示，正常），装完告诉我。」不要替用户输密码。 |
| Mac 没有 Python 3 | macOS 第一次运行 `python3` 会弹「安装命令行开发者工具」，让用户点「安装」，等它装完。 |
| Windows 弹出管理员确认 | 「屏幕上弹了一个『是否允许更改』的窗口，点『是』。」 |
| Windows 没有 winget | 让用户在微软商店装「应用安装程序」，或者去 python.org、gyan.dev 手动下载安装包（装 Python 时勾上 Add to PATH）。 |
| 下载一直失败 | 先自己重试一次（脚本会自动换清华镜像 / hf-mirror）；还不行，问用户是不是开了代理或公司网络，请他换个网络再试。 |

## 国内网络

脚本自己处理，不用问用户：
- pip：测速后在清华镜像和官方源里挑快的；失败自动换另一个。
- 转写模型：连不上 huggingface.co 自动用 hf-mirror.com。
- Homebrew：连不上 ghcr.io 自动用清华的 bottle 镜像。

## 做完

用一句话告诉用户：「环境好了」（或「环境好了，转写模型还在后台下载」），然后进第 2 步。
