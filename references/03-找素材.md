# 第 4 步：找素材

## 先问用户

1. **要不要我按口播稿找素材？** 用户自己的素材够了，或者想全用动画画面，就跳过这一步。
2. **找哪类？** 一次问清，两个选项：
   - **只要可商用的（推荐）**：图库里能商用的照片和视频（CC0、公有领域、CC BY、Pexels、Pixabay）。接广告、商单也能用。
   - **再加官方引用素材**：公司、机构官网和官方账号发的演示视频、产品图。画面最贴题，但只算「适当引用」：科普、评论类视频一般没问题，**接商单、广告的视频不能用**。

   用户没选第二项就**不找官方素材**，哪怕某句话用官方素材最合适。

## 列出要配画面的句子

读 `_工程/口播稿.txt`（用的是三列脚本表时读 `_工程/脚本表.json`，「画面」那列写了的照着找）。挑出**需要真实画面**的句子：
- 提到具体的人、公司、产品、地方、事件 → 找照片或官方素材
- 讲一个场景（「工厂里的机器人」「城市夜景」）→ 图库视频
- 抽象概念、数字、步骤、对比 → **不找素材**，第 8 步用动画画

一条 3 分钟的口播一般 8–15 个素材就够，别每句都配。把列表给用户看一眼（一行一句：口播 → 打算找什么），用户没意见就开始找。

## 可商用素材

```
python find_assets.py search "humanoid robot factory" --type video --n 12
```
- 关键词用**英文**，搜到的多得多。人名用英文名（Yann LeCun）。
- `--type image|video`，竖屏片子加 `--orient 竖`。
- 结果编号 c1、c2…，同时出一张候选拼图 `_工程/候选拼图/<关键词>.jpg`。**一定先打开拼图看画面**，标题和画面常常对不上。
- 挑中了：
  ```
  python find_assets.py get c3 --line "持有这个观点的人中，最有名的当属杨立昆" --name 杨立昆_演讲
  ```
  视频只要一段时：加 `--from 2 --to 8`（秒）。下载到 `3_素材/找来的/`，自动记进素材清单。
- 一个词搜不到好的，换说法再搜（「robot arm assembly line」「warehouse robot」）；三次都不行就跳过：
  ```
  python find_assets.py skip --line "…" --reason "图库里没有合适的"
  ```

Pexels、Pixabay 的视频多、质量好，但要免费 key。`python find_assets.py keys` 看状态和申请方法（注册后在网页上复制 key，两分钟）。用户愿意弄就让他把 key 发给你，`python find_assets.py setkey pexels <KEY>`；不愿意就只用 Openverse 和 Wikimedia，不影响流程。

## 官方引用素材（用户选了才找）

1. 自己上网找**一手来源**：公司官网、官方博客、官方 YouTube / B 站账号、发布会页面。不要用搬运号、营销号、新闻站转载的视频。
2. 下载：
   ```
   python find_assets.py official "<视频页面或直链>" --line "…" --name AMI官网 --source "AMI Labs 官方" --page "<来源页面>"
   ```
   - 视频超过 10 秒又没给区间：只下原片到 `_工程/官方原片/`。用 `python contact_sheet.py <原片> 0 <时长> 3 看片.png` 看完，挑最贴的一段，再带 `--from 0:03 --to 0:12` 跑一次。**最多截 10 秒**。
   - 台标、水印保留，不裁掉。
3. 找不到一手来源就 `skip`，不要拿来路不明的视频凑。

## 给用户删

```
python find_assets.py sheet
```
出 `3_素材/找来的/素材拼图.jpg`（每张标了编号和对应的口播）。**停下来**，跟用户说：
> 素材找好了，一共 N 个，在 `3_素材/找来的/` 里，`素材拼图.jpg` 能一眼看完。不要的直接删掉文件，删完告诉我。也可以在 `素材清单.xlsx` 里看每个的来源和授权。

用户删完：
```
python find_assets.py sync
```
清单里对应的行跟着删掉。

## 素材清单

`_工程/素材清单.json` 是底稿，每次改动都会重新生成工程根目录的 `素材清单.xlsx`：编号、文件、对应口播、来源、授权、署名、分类（可商用 / 引用·非商用授权）。
Excel 正开着这个表时写不进去，脚本会提示，请用户关掉 Excel 再跑一次。

交付时 `python find_assets.py credits` 生成 `成片/授权清单.md`（第 9 步做）。
