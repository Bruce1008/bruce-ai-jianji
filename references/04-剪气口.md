# 第 5 步：剪气口（粗剪）

目的：在做画面之前先把口播剪干净：收紧停顿，删掉重说、说一半重来的半句，删掉「这段不要了」「重来」这种口头指示。之后所有时间都按剪好的 `口播_粗剪.mp4` 来对。

停顿规则来自大师的AI小灶公开的气口提示词，已经写在 `cut_voice.py` 里，不用手动算。

## 1. 转写原片

```
python transcribe.py "<TAKE>" --terms "世界模型, 杨立昆, World Labs, AGI"
```
- `<TAKE>` 是第 3 步 `intake.py` 最后一行给的路径。
- `--terms`：从口播稿里挑人名、产品名、英文词，逗号隔开。Whisper 最常听错这些，给了准很多。
- 3 分钟的口播：苹果芯片 1–2 分钟，其他电脑 3–10 分钟。超过 2 分钟的用后台跑。

## 2. 扫描

```
python cut_voice.py scan "<TAKE>"
```
写出 `粗剪_扫描.md` 和一个待填的 `cut_plan.py`。口播稿默认用 `_工程/口播稿.txt`。

`粗剪_扫描.md` 可能很长：先看开头几行（时长、停顿数、语速），再按标题 grep 各节。各节怎么处理：

| 节 | 怎么处理 |
|---|---|
| 疑似重说 / 说一半重来 | 每条都附了现成的 DROP 行。看前后文确认后抄进 `cut_plan.py`。 |
| 主转写漏掉的话 | 常是被吞掉的重说，看时间对上哪句，重复的就删。 |
| 有声音但没字 | 「嗯」「啊」、咂嘴、吸气。在句子中间的删，DROP 写 `gap=0.04`；长而响的可能是说话，别删。 |
| 稿子里有、录音里没有 | 只告诉用户，不处理。可能是他临时改了词，也可能漏录了。 |
| 录音里有、稿子里没有 | 多半是口头指示（「这段不要了」「重来」「刚才那句再来一遍」），连同它指的那段一起删；即兴补充的话保留。 |

**重说挑哪一遍**：没有口误、卡壳、吞音，语调最饱满、重音准的那遍。差别不明显时把候选（时间 + 原话）列给用户选；还分不出来，用后录的那遍。人物姿势或位置差很多的两遍不要拼在一起。

**变速**：默认不变速（`SPEED = 1.0`）。扫描报告里语速低于 4.5 字/秒时，问用户一句：「你说话偏慢，要不要整体加快一点？（音调不变）」，要的话写 `SPEED = 'auto'`（加速到约 5.5 字/秒，最多 1.2 倍）。

## 3. 剪

```
python cut_voice.py cut "<TAKE>"
```
写出：
- `口播_粗剪.mp4`（只有录音时是 `口播_粗剪.wav`）
- `粗剪说明.md`：剪了什么、为什么、要回头听的拼接点
- `cut_map.json`：原片和粗剪之间的时间对照

## 4. 转写粗剪

```
python transcribe.py 口播_粗剪.mp4 --terms "…"
```
`words.txt` 现在是粗剪后的时间。**之后的字幕、画面、音效全按这个时间来。**（第一次 scan 时，原片的转写已经改名成 `words_raw.txt`、`transcript_raw.json`。）

## 5. 给用户听

**停下来**，用两三句话说清楚：
> 粗剪好了：`_工程/口播_粗剪.mp4`，原来 X 分 X 秒，现在 Y 分 Y 秒。去掉了 N 处重说和 M 处长停顿（详细在 `粗剪说明.md`）。你听一遍节奏，特别是 a 秒、b 秒这两个拼接点，有不对的告诉我。

用户要改：改 `cut_plan.py` 的 DROP，再跑第 3、4 步。

用户只要粗剪（「帮我剪个气口」）：到这里就交付 `口播_粗剪.mp4` 和 `粗剪说明.md`，不往下做。

## 画面做好以后又要改粗剪

尽量在这一步就定下来。真要改：先把旧的 `words.txt` 复制成 `words_旧.txt`，改 DROP、重跑上面第 3、4 步，然后对照新旧 `words.txt`，把 scenes.py、cues.py 里拼接点之后的时间挪过去，字幕重跑 `python make_subs.py --align subs.txt`。
