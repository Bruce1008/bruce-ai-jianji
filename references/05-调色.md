# 第 6 步：调色

只有录音、没有画面的口播跳过这一步。

## 做什么

把口播里人的颜色调顺眼：去黄、提亮、稍微加点对比。生成一个调色文件，渲染时自动套在人物画面上，**原视频不动**。

规则（文章里踩过的坑，已经写进 `grade.py`）：
1. 去黄只动黄-蓝这一个方向，脸上的红润不动，也不靠降饱和度去黄（会发灰）。
2. 只调白平衡、亮度、对比度，不做颜色映射：衣服、背景的颜色不会跟着参考图跑偏。
3. 白平衡只看画面里接近灰白的地方（墙、白衣服）。参考图背景是蓝的，也不会把人调蓝。
4. 中途灯光变了（分几次录的）：自动分段，每段各调一次，调到同一个目标。
5. 整段用固定的调色，不一帧一帧变，不会忽明忽暗。

## 怎么做

先问一句：「有没有喜欢的调色参考？有的话放一张截图到 `4_参考图`，文件名带『调色』两个字；没有我按默认规则调。」用户说没有就直接跑。

```
python grade.py                       # 有「调色」参考图自动用；没有用默认规则
python grade.py --ref ../4_参考图/xx.jpg  # 指定参考图
python grade.py --strength 0.6        # 调得轻一点（默认 0.8）
```
默认调 `口播_粗剪.mp4`。写出 `grade.json`、`grade.cube`（分段时是 `grade_1.cube`、`grade_2.cube`…）、`调色对比.png`（左原片、右调过，取了几个时间点）。

自己先看一眼 `调色对比.png`：脸色自然、不发灰、不发青就行。偏了就降 `--strength` 重跑。

## 给用户看

**停下来**，给用户看 `调色对比.png`，一句话说调了什么（`grade.py` 会打印，比如「去黄一点、提亮一档、对比稍加」）：
- 满意 → 第 7 步。
- 「再淡一点 / 再浓一点」→ 改 `--strength`（0.4–1.0）重跑。
- 「不要调色」→ `python grade.py off`。

调色在渲染时才生效，这一步不用渲染视频。

## 调完色：人物取景（不用问用户，自己做）

定下人物全屏、横屏小窗各裁原片的哪一块。原片方向和成片不一致时（竖着拍、做横屏）这一步最要紧：裁错了小窗里会只剩半张脸。

```
python framing.py
```
看 `人物取景.png`：
- 上排是原片 3 个时间点：灰色 10% 网格，绿十字 = 现在设的人脸位置，红框 = 人物全屏裁的那块，橙框 = 横屏小窗裁的那块。
- 下排是实际效果：人物全屏 + 每个时间点的小窗。
- **要的样子**：小窗里整个头（头顶、下巴）和一点肩膀都在，人在中间；人物全屏里至少整张脸都在（竖拍做横屏时只能裁到头，正常）。

绿十字要落在**两眼中间**。没对准就照网格读出那一点的 x、y，试一次：
```
python framing.py --focus 0.5,0.48
```
小窗里人太小 / 太大：加 `--zoom 1.2`（更紧）或 `--zoom 0.85`（更松）。对了就存下来：
```
python framing.py --focus 0.5,0.48 --save
```
存进 `project.json`，风格预览和渲染都按它裁。
