# 第 7 步：选风格

风格决定画面长什么样：配色、字体、部件（标题、贴照片、圈重点、盖章…）、转场、字幕和人物小窗的样子。

## 现在有哪些风格

看 `<技能>/styles/` 下有哪些文件夹，每个有 `theme.py` 的就是一个能用的风格。每个风格的 `风格卡.md` 第一段是一句话介绍，「适合 / 不太适合」写了它适合什么内容。`静帧/` 里有几张成品截图。

| 风格 | 一句话 | 适合 |
|---|---|---|
| 手绘笔记 | 米白纸上墨蓝钢笔线稿，只用一种橙色强调，字一个一个写出来，像在记研究笔记 | 概念拆解、学习笔记、教程 |
| 扁平流程图 | 奶油底、琥珀黄色块、特粗黑字、带厚度的彩色块，干净明快 | 流程、步骤、对比、轻松科普 |
| 黑底科技 | 近黑底、暖光、金色星尘，金色宋体由虚到实浮出来，结论一枚红印章 | AI 新闻、发布会、有分量的深度内容 |
| 复古报刊 | 白报纸、藏青和报纸红，压窄宋体标题、打字机正文、黑白新闻照、红笔改稿 | 新闻评论、事件复盘、人物故事 |
| 华尔街财经 | 深藏青演播室、金属银标题、金色大数字、金 / 绿 / 红胶囊 | 财经、商业、融资、数字多的内容 |

以 `styles/` 里实际有的为准。5 个风格的部件名字、参数都一样（`styles/部件.md`），所以第 8 步写好的画面换哪个风格都能直接渲。

华尔街财经的画面方向参考了 [wallstreet-explainer](https://github.com/HeyChengC/wallstreet-explainer)（代码是重新写的，没打包它）。用户想要它原版的效果，让他自己去装那个技能。

## 怎么做

1. 读口播稿，看内容是什么类型（概念讲解、教程、财经数据、新闻评论…）。
2. 给用户介绍现有风格：每个一句话，加上「适合你这条」的推荐和理由。把 `静帧/` 里的截图给他看。
3. 用户挑一个（或两个想对比），出带他自己的风格预览图：
   ```
   python style_preview.py 手绘笔记
   ```
   在 `_工程/` 里运行，会从 `口播_粗剪.mp4` 里取一帧当小窗里的人（套上调色），横竖屏按工程来。出 `风格预览/手绘笔记_横屏.png`（几页拼一张）。
   这几页是风格自带的示例，不是他的内容；第 8 步才按他的口播做。
4. **停下来**，给用户看预览图，问：「用这个风格吗？」
5. 用户选定：
   ```
   python style_preview.py 手绘笔记 --use
   ```
   把 `theme.py` 复制进 `_工程/`，示例页面复制成 `示例_手绘笔记.py`（写画面时照着抄），`project.json` 里记下风格。

## 看完开头 15 秒想换风格

scenes.py 只用了通用部件，换风格不用改画面：
1. 先试看（不动工程里的 theme.py）：
   ```
   BAJ_STYLE=黑底科技 python render.py video 预览_黑底科技.mp4 0 15
   BAJ_STYLE=黑底科技 python mix_master.py ../成片/开头15秒_黑底科技.mp4 --video 预览_黑底科技.mp4
   ```
   Windows 先 `set BAJ_STYLE=黑底科技`，再跑后面两条（不带前缀）。
2. 用户定了：`python style_preview.py 黑底科技 --use`，之后全片都用它。

## 用户想要的风格这里没有

照他描述或给的参考图，在最接近的现有风格上改：复制那个 `styles/<风格>/` 成 `styles/<新名字>/`，改 `theme.py` 里的配色、字体、背景和部件的画法（**部件名字、参数、返回值不改**，见 `styles/部件.md` 最后一节），跑 `style_preview.py <新名字>` 给他看，满意了再 `--use`。改动大时先说清楚「这要多花一些时间」。

不要照抄别人的商业作品、知名 IP 的画风。
