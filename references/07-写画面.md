# 第 8 步（上）：字幕、镜头表、写画面

开头 15 秒和全片都按这份做。先只做开头 15 秒，给用户看过、改到满意，再做全片。

所有时间都是**粗剪后的口播时间**，从 `words.txt` 里取（每段一行：`字@秒 字@秒 …`）。

## 1. 字幕

```
python make_subs.py                    # -> subs_draft.txt：转写断好行的草稿
```
把草稿改成 `subs.txt`：
- 用口播稿校对错字、人名、产品名（Whisper 常把专有名词听错），但**保留他实际说的话**，不照稿子改。
- 一行一条字幕，在自然停顿处断行。横屏每行不超过 18 字，竖屏不超过 13 字。
- 不要标点。不写时间。

```
python make_subs.py --align subs.txt   # -> subs.srt：每个字对到转写的时间上
```
对齐率低于 90% 说明 subs.txt 和录音差太多，看提示改。

## 2. 镜头表

先把镜头表写在 `scenes.py` 开头的文档字符串里，再写代码。一行一个镜头：

```
| 镜头 | 时间 | 台词 | 画面 |
|---|---|---|---|
| 1 | 0.00–1.00 | 为什么有人说 | 人物全屏 |
| 2 | 1.00–5.30 | 世界模型才是通往 AGI 的唯一路径呢 | 标题「世界模型」，逐字写出后半句，「唯一路径」橙色色块，大问号 |
```

怎么分镜：
- **开头 15 秒最要紧**：第一句（问题、反常识、结果先给）人物全屏说，1–2 秒内切到第一个画面；15 秒内至少 3 个画面，每个都有明显的动作。
- 一个画面 3–8 秒，对应一句或半句话；超过 8 秒就拆成两页，或者同一页里分几拍出东西。
- **画面全屏为主，人物全屏约占三分之一**：观点、情绪、转折、结论这几句给人物全屏；讲事实、数字、例子、步骤时出画面。
- 每页只讲一件事：一个关键词、一个数字、一张照片加一句说明。最多 3 组东西。
- 口播里的关键词就是画面里的字：说「图灵奖得主」，画面就写「图灵奖得主」，说出来前 0.05–0.1 秒开始出现。
- 有素材的句子用素材（第 4 步的 `素材清单.xlsx` 里写了每个素材对应哪句话）；抽象的概念、数字、步骤、对比用风格部件画。
- 口播稿里「（画面…停留N秒）」的地方：这一页加 `hold=N, done=<这页最后一个字的结束时间>`，渲染时自动定格 N 秒、口播暂停。
- 官方引用素材：照片的说明写「画面来源：XX 官方」。

## 3. 写 scenes.py

在 `_工程/` 里新建 `scenes.py`。先读三份东西，**别凭记忆写部件**：
- 部件说明：`<技能>/styles/部件.md`（5 个风格通用的部件：名字、参数、返回值、音效名、转场）
- 风格卡：`<技能>/styles/<风格>/风格卡.md`（这些部件在这个风格里长什么样、配色、转场）
- 示例：`_工程/示例_<风格>.py`（部件的真实用法，照着抄）

**只用通用部件和 `T.ACCENT` / `T.ACCENT2` / `T.INK` / `T.MUTE` 这几个颜色名，不写死色值，不用某个风格独有的部件。** 这样用户看了开头 15 秒想换风格，只换 theme.py 就行，scenes.py 一个字不用改。

骨架：
```python
"""<片名>：横屏，<风格>。时间都取自 words.txt（粗剪后的口播）。

<镜头表>
"""
import theme as T                # 一定在 from lib import * 前面
from lib import *  # noqa
import lib
import layout as L

VOICE = '口播_粗剪.mp4'
M = '../3_素材/找来的/'
LX = L.PIP_SAFE[2] + 40          # 横屏：内容从人物小窗右边开始；竖屏写 LX = 60
RX = W - 70


def p_question(c, t, S):         # 一个镜头一个函数：c 画布，t 口播时间，S.t0 这个镜头开始的时间
    T.paper(c, t)                # 先铺底；head='第 1 段 · xx' 加页眉
    with T.cam(c, t, S.t0):      # 整页慢推
        T.title(c, '世界模型', (LX + RX) / 2, 330, 124, t, 1.0, sub_en='WORLD MODEL', seed=1)
        ...


TIMELINE = [
    dict(t=0.00, host=True),                     # 人物全屏
    dict(t=1.00, mg=p_question),                 # 画面（默认转场看风格卡）
    dict(t=5.30, mg=p_lecun, tr=T.ALT_TR),       # 换话题：用这个风格的第二种转场
    dict(t=14.75, host=True),
]
CHAPTERS = [(0.0, '开头')]
```

TIMELINE 每一条：
| 键 | 意思 |
|---|---|
| `t` | 这个镜头从口播第几秒开始（下一条的 `t` 就是它结束的时候） |
| `host=True` | 人物全屏。横屏：左上角小窗放大成全屏；竖屏：切到人物全屏 |
| `mg=函数` | 画面全屏，由这个函数画。横屏时左上角一直有人物小窗 |
| `clip=(路径, 起点秒, 速度, None)` | 整屏放一段视频素材（不加纸、不加边框） |
| `tr` / `td` | 转场名字 / 秒数，不写用风格默认的；换话题写 `tr=T.ALT_TR` |
| `pip=False` | 横屏：这一页把人物小窗藏起来（画面需要整屏时） |
| `hold=N, done=秒` | 定格 N 秒（只给口播稿写了「停留N秒」的页面） |

版式：
- **横屏 1920x1080**：左上角 `layout.PIP_SAFE`（0,0 到 384,488）是人物小窗，别放东西；字幕在底部 y≈985，内容别低于 y 920。
- **竖屏 1080x1920**：内容放在 y 120–1330，字幕在 y 1415，左右各留 60 以上。

视频素材放进照片框：`img = T.clip_img(S, 'k1', M + '05_xx.mp4', 起点秒, t, 640, 360)`，再 `T.photo(c, img, …)`。
同一页里每个部件给不同的 `seed`。
排一行东西要先知道宽度：`T.tag`、`T.block_word`、`T.number` 传 `a=0` 只返回宽度不画；纯文字用 `text_w(字, 字号, 'hand')`。别用某个风格的内边距去算。

## 4. 写 cues.py（音效）

转场声音自动配，cues.py 里只写画面里的动作声：

```python
from cuelib import cue, transition_cues
import scenes as SC


def scene_cues():
    C = []
    a = C.append
    a(cue(1.25, '@drop'))              # cue(口播时间, 动作名, 比这个风格默认的响多少 dB)
    a(cue(2.14, '@write'))
    a(cue(9.95, '@mark', 1))
    a(cue(13.36, '@stamp'))
    return [x for x in C if x]         # 有的风格某个动作不出声（返回 None）


def all_cues():
    return sorted(transition_cues(SC) + scene_cues(), key=lambda c: c[0])
```
- 一个音效对一个画面动作，时间就是那个动作开始的时间。没有动作的地方不放音效。
- 写动作名（`@write` 逐字、`@drop` 落下、`@pop` 弹出、`@mark` 圈和划线、`@stamp` 结论章、`@stick` 贴上、`@tick` 勾叉、`@number` 大数字、`@whoosh` 飞进来），具体是什么声音由风格决定，换风格不用改 cues.py。
- 真要指定某个声音也可以直接写音效名（`cue(t, 'shutter', -6)`），名字看 `<技能>/assets/sfx/README.md`；但换风格时这一声不会跟着变。
- 音效要轻：风格里已经配好音量，一般不用再调；重点处（结论）可以 `+1`～`+2`，太密的地方 `-2`。
- 只有音效，不加背景音乐（用户在 `5_BGM` 里放了才加）。

## 5. 先看静帧，再跑检查

```
python stills_sheet.py 静帧检查.png 0.6 2.6 4.9 7.2 10.4 12.9 14.4
```
每个镜头挑 1–2 个时间（东西刚出齐时、这页快结束时），自己看：字有没有出框、压到小窗或字幕、有没有重叠、页面是不是一边太空。有问题改 scenes.py 再出，几秒一次，很便宜。

```
python checks.py all 0 15         # 只查开头 15 秒；全片写 python checks.py
```
看 `检查/检查报告.md`：
- **卡点**：「音效响了画面没动」「画面提前动了」→ 挪音效时间或动画时间。
- **丰富度**：超过 2.5 秒画面几乎不动 → 加一个次要动作（下一个东西落下、圈一下、慢推）。
- **手机上看**：小于 48 px（竖屏 27 px）的字列出来；来源说明这类小字可以不管，正文和关键词要放大。
- **被人物小窗挡住**：挪开。
