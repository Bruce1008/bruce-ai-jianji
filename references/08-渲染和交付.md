# 第 8 步（下）和第 9 步：渲染、混音、交付

渲染只做两次：**开头 15 秒预览**和**最终成片**。改动先用静帧看（`stills_sheet.py`），用户没要求就不重渲；只改了音效就只重跑混音。

## 开头 15 秒预览

1. 结束点：找 15 秒附近一句话说完的地方（看 `words.txt`），最好正好是下一个镜头开始的时间。下面用 14.75 举例。
2. 渲画面（不含声音）：
   ```
   python render.py video 预览.mp4 0 14.75
   ```
   15 秒在苹果芯片的 Mac 上约 20–40 秒，其他电脑慢 2–4 倍。超过 2 分钟的用后台跑。
3. 混音（口播 + 音效，响度调到 -14 LUFS，抖音、小红书的标准）：
   ```
   python mix_master.py ../成片/开头15秒预览.mp4 --video 预览.mp4
   ```
   它会按 `预览.range.json` 只截这一段的声音。
4. 自己先抽几帧看：
   ```
   python frames_at.py ../成片/开头15秒预览.mp4 预览抽帧.png 0.5 3 6 9 12 14
   ```
   人物、小窗、字幕、画面都在，没有黑帧、没有错位，再给用户。
5. **停下来**，跟用户说：
   > 开头 15 秒做好了：`成片/开头15秒预览.mp4`。看看画面风格、节奏、音效合不合适。有要改的直接说（比如「第 5 秒那页字太小」「音效太吵」），满意了我就做全片。

   用户提的改动：改 scenes.py / cues.py → 出静帧确认 → 再渲一次这 15 秒给他看。画面和风格在这一步定死，全片照这个标准做。

## 全片

1. 按 07-写画面.md 把剩下的镜头写完（镜头表 → scenes.py → cues.py）。长片子分几段写，每写完一段就出静帧看。
2. 全片检查：
   ```
   python stills_sheet.py 静帧检查_全片.png <每个镜头一个时间>
   python checks.py
   ```
   静帧太多就分几张出（每张 10–16 帧）。
3. 渲画面，用后台跑（3 分钟的片子在苹果芯片上约 5–10 分钟）：
   ```
   python render.py video video_only.mp4
   ```
4. 混音：
   ```
   python mix_master.py ../成片/成片.mp4
   ```
   同时写出 `成片/字幕.srt`（成片时间，含定格）。
5. 授权清单：
   ```
   python find_assets.py credits
   ```
   写出 `成片/授权清单.md`。没用第 4 步找素材也跑一次，里面会写「自带素材的版权由你负责」。
6. 抽帧自查：`python frames_at.py ../成片/成片.mp4 成片抽帧.png <10 个左右的时间>`。

用户要无字幕版（要多渲一遍，先问）：
```
python render.py video video_nosub.mp4 --nosub
python mix_master.py ../成片/成片_无字幕.mp4 --video video_nosub.mp4
```

## 交付报告

`成片/` 里应该有：`成片.mp4`、`字幕.srt`、`授权清单.md`（和用户要的 `成片_无字幕.mp4`）。

跟用户说（大白话，几句话）：
1. **用了官方引用素材时，第一句就说**：「这条用了 N 段官方引用素材（标了『画面来源』）：发科普、评论没问题，接广告、商单要换掉。」
2. 成片在哪、多长、横屏还是竖屏。
3. 发布时要贴的署名：`授权清单.md` 里 ``` 框起来的几行（「画面来源：…」和 CC BY 署名），原样复制到视频简介里。
4. 自带素材的版权由他自己负责。
5. 看完要改：「把要改的地方写进 `修改表.xlsx`（第几秒、改什么），写完跟我说『按修改表改』。」

## 中间文件

`_工程/` 里的 `video_only.mp4`、`预览.mp4`、`stills/`、`检查/`、`mix_pre.wav` 都能删，不影响以后改片子（改的时候会重新生成）。用户问「能删吗」时这样回答；不要主动删。
