# 第 10 步：按修改表改

用户看完成片，把要改的地方写进工程根目录的 `修改表.xlsx`（时间、问题、截图、类型、状态），然后说「按修改表改」。

**修改表只读。** 不改它、不标「已改」：改完在对话里报告改了哪几行，用户自己去标。

## 1. 读表

```
python revisions.py
```
打印每一行「待改」：行号、成片时间换算成的口播时间（有定格时两者不一样）、问题、截图路径、类型，以及落在 scenes.py 的哪个镜头。模板自带的灰色示例行和「已改」的行自动跳过。最后一行 `NEXT=成片_vN.mp4` 是这次的新版本文件名。

有截图的行，先打开截图看清楚用户说的是哪里。

用户直接在对话里说要改什么（没写表）也照做，报告时说清楚改了什么。

## 2. 按类型改

| 类型 | 一般改哪里 |
|---|---|
| 人物画面 | 人物全屏 / 小窗里脸的位置和大小：`python framing.py --focus x,y --zoom z` 看图调好再 `--save`（05-调色.md 最后一节）；花字挡脸：挪画面里的东西；颜色：重跑 `grade.py`（05-调色.md） |
| 动画 | scenes.py 里那个镜头的画面函数：字号、位置、出现时间、换素材、换部件 |
| 字幕 | 错字改 `subs.txt` 再 `python make_subs.py --align subs.txt`；字号、样式在 theme.py 的 `sub` 和 layout.py 的 `SUB_SIZE` |
| 声音 | 音效：cues.py 改音量（dB）或删掉；底噪：scenes.py 的 `GATE_DB`（-38 更干净，-44 更保留尾音）；口水音、口头禅：要动粗剪，见 04-剪气口.md 最后一节 |
| 节奏 | 镜头太短 / 太长：挪 TIMELINE 的 `t`，或拆页、合页；需要停一下：加 `hold=N, done=秒` |
| 表达 | 画面上的说法、标题、关键词：改画面函数里的字。要删掉某句话：动粗剪（04-剪气口.md） |
| 全局 | 整条片子统一改：比如所有标题都换个颜色、全片音效都轻一点，改 theme.py 或 cues.py 的整体设置 |

做不到的（比如「这里换成我本人在工厂里的画面」但没有这段素材）不硬改，报告里说清楚缺什么、要用户提供什么。

## 3. 验证

- 每改一处，出那个时间的静帧看（`python stills_sheet.py 改动检查.png <口播时间> …`）。
- 动了画面就再跑一次 `python checks.py`。
- **所有行都改完、静帧都对了，才渲一次全片**：
  ```
  python render.py video video_only.mp4
  python mix_master.py ../成片/<NEXT 给的文件名>
  ```
  只改了音效或声音：不重渲画面，只重跑 `mix_master.py`（用已有的 `video_only.mp4`）。
- 旧版本 `成片.mp4` 留着，不覆盖。
- 素材有增删：`python find_assets.py credits` 更新授权清单。

## 4. 报告

一行一条，对上表里的行号：
> 改好了：`成片/成片_v2.mp4`
> - 第 6 行（00:07 杨立昆那页字太小）：便签上的字从 56 号放大到 68 号。
> - 第 7 行（00:12 以后 音效太吵）：后面的音效整体调低 4 dB。
> - 第 10 行（00:05–00:09 照片停太久）：照片页缩短 1 秒，后面一页提前出来。
> - 第 8 行（字幕再大一点）：没改，字幕已经是手机上看的最大号，再大会挡画面。要的话我可以改成两行显示。
>
> 你看过没问题，把这几行的状态改成「已改」。还有要改的继续往表里写。
