# 华尔街财经

深藏青的布纹底，顶上打下一束光，四周压着很重的暗角，像财经节目的演播室。标题是金属银的特粗黑体，上面一行金色英文小字；大数字是窄体的金色数字，数上去、落定后一道反光扫过；标签是金边深色小牌；重点词是金 / 绿 / 红胶囊；照片是白色新闻卡 + 红色来源标签；结论是一块深色金边牌子砸下来。

**适合**：财经、商业、融资、公司财报、「这家公司值多少钱」、数字很多的内容。
**不太适合**：轻松的教程（用扁平流程图或手绘笔记）。

画面方向参考了 [wallstreet-explainer](https://github.com/HeyChengC/wallstreet-explainer) 那类财经讲解视频的感觉（这个技能没有打包它，想要它原版的效果请去它的仓库）；这里的代码和部件全是重新写的，跑在 bruce-ai-jianji 的 Python 引擎上。

静帧：`静帧/横屏_标题页.jpg`、`静帧/横屏_照片页.jpg`、`静帧/横屏_数字页.jpg`、`静帧/竖屏.jpg`

## 配色

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 底 `NAVY0` → `NAVY1` | `#101a30` → `#050912` | 全屏底色 |
| 顶光 `SPOT` | `#344e80` | 顶上那束光 |
| 金属银 `SILVER_G` | `#ffffff` → `#dee4ee` → `#96a2b4` → `#e8ecf4` | 标题 |
| 金 `GOLD_G` | `#ffeeba` → `#f2cc74` → `#cc9a3e` | 大数字、大号标点、结论牌上的字 |
| 金边 `GOLD` | `#c9a95a` | 标签边、卡片边、线、圈 |
| 金胶囊 `GOLDC`（`ACCENT`） | `#d8b45a` | 第一个重点词 |
| 绿胶囊 `GREEN`（`ACCENT2`） | `#36a364` | 第二个重点词、涨、对 |
| 红胶囊 `REDC` | `#d4534f` | 跌、错（`block_word(..., color=T.REDC)`） |
| 勾 / 叉 `OK` / `NO` | `#2f9e5b` / `#d23c3c` | 勾、叉 |
| 来源红 `SRC_RED` | `#b8282f` | 照片上的来源标签 |
| 正文 `TXT` | `#f6f7fa` | 正文、字幕 |

绿 = 涨 / 对，红 = 跌 / 错，别反着用。

## 字体

思源黑体：正文 700、标题和重点词 900、字幕 800。大数字 Bebas Neue（窄体），英文小字 Montserrat 700。

## 部件长相（用法见 `styles/部件.md`）

| 部件 | 在这个风格里 |
|---|---|
| `paper(head=)` | 深藏青渐变 + 细布纹 + 顶上一束慢慢晃的光 + 重暗角；head 是左上角金色竖条 + 金色小字 + 渐隐金线 |
| `title` | 金属银特粗字（带深色投影）从下面升上来、由虚到实，上面一行金色英文往两边拉开 |
| `tag` | 深色小牌 + 细金边 + 金字，从左边滑进来 |
| `write` | 白字带投影，一个字一个字淡入上浮 |
| `block_word` | 金 / 绿 / 红渐变胶囊，弹出来 |
| `number` | Bebas 金色大数字，从 0 数上去，落定后一道反光扫过 |
| `mark` | 金色问号 / 叹号，弹出来 |
| `stamp` | 深色金边牌子 + 金字，砸下来震一下，反光扫过 |
| `hunder` / `hcircle` / `harrow` | 发光的金线 / 金圈 / 金色弧形箭头（实心箭头） |
| `hcheck` / `hcross` | 绿色圆标白勾 / 红色圆标白叉 |
| `marker` | 半透明黄色荧光带，底边一道亮黄 |
| `sheet` | 深色玻璃卡 + 细金边 + 顶上一道高光 |
| `photo` | 白色新闻卡里的图，左下角红色来源标签 |

## 转场

| 名字 | 样子 | 什么时候用 |
|---|---|---|
| `whip`（默认） | 甩镜头：整页往左一甩，强烈横向拖影，下一页甩进来 | 大部分时候 |
| `zoom`（内置） | 推近穿过去 | 从总览进到细节 |

## 字幕和人物小窗

- 字幕：白色特粗字 + 深色描边和投影，不垫底。
- 人物小窗：细金边 + 外面一圈深色。

## 音效

逐字出来 `tick`，卡片落下 `low_swish`，弹出 `click`，结论牌 `impact`，大数字 `landing`，转场 `whip`。干脆、有节奏。
