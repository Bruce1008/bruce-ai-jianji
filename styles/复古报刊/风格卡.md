# 复古报刊

白报纸、藏青和报纸红两种油墨，角上一块淡蓝网点。标题是压窄的特粗宋体，下面粗细两道横线，像报头；正文像打字机一个字一个字打出来；重点词是带白边的红 / 藏青色块；照片是黑白新闻照 + 图注；改稿用红笔圈、勾、叉；结论盖一个红色审稿章。

**适合**：新闻评论、事件复盘、「这件事是怎么发生的」、人物故事、历史回顾。
**不太适合**：很炫的产品发布（用黑底科技）；数字特别多的财经内容（用华尔街财经）。

灵感来自 [dashi-animationstyle](https://github.com/chuspeeism/dashi-animationstyle) 的「复古报刊」风格；这里的代码和部件是重新写的，跑在 bruce-ai-jianji 的 Python 引擎上。

静帧：`静帧/横屏_标题页.jpg`、`静帧/横屏_照片页.jpg`、`静帧/横屏_数字页.jpg`、`静帧/竖屏.jpg`

## 配色

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 报纸白 `PAPER` | `#fdfdfb` | 全屏底色 |
| 藏青 `NAVY`（`ACCENT2`） | `#1d3d8a` | 标题、报头、粗细两道线、数字、第二个重点词 |
| 报纸红 `RED`（`ACCENT`） | `#bb3633` | 栏目标签、第一个重点词、改稿红笔、审稿章 |
| 浅蓝 `LIGHT` | `#cfd6ee` | 高亮、网点 |
| 正文黑 `BODY` | `#1a1a1a` | 正文、字幕 |
| 灰 `GRAY` | `#737574` | 日期、图注、引线 |
| 分隔线 `RULE` | `#ceced0` | 卡片边 |

照片一律做成黑白。别加渐变、发光、圆角大胶囊。

## 字体

标题、重点词、数字：思源宋体 900，标题横向压窄到 82%。正文思源黑体 500，字幕和标签思源黑体 700。英文小字 Playfair Display。

## 部件长相（用法见 `styles/部件.md`）

| 部件 | 在这个风格里 |
|---|---|
| `paper(head=)` | 报纸白 + 纸纹 + 右下角淡蓝网点；head 是报头：左边藏青栏目名、右边今天的日期，下面粗细两道藏青线（不给 head 只有两道线） |
| `title` | 压窄的藏青宋体从左往右印出来，上面一行红色英文，下面粗细两道线往两边拉开 |
| `tag` | 方角红底白字，从左往右露出来 |
| `write` | 打字机一个字一个字打出来，后面跟一条藏青光标 |
| `block_word` | 带白边的红（或藏青）色块白字，从左往右印出来 |
| `number` | 藏青宋体大数字，从 0 数上去，从下往上印出来 |
| `mark` | 红色宋体问号 / 叹号，像盖上去一样落定 |
| `stamp` | 红色空心审稿章（粗细双框），砸下来震一下，油墨有点不匀 |
| `hunder` / `hcircle` | 红笔划一道 / 红笔歪着圈一圈 |
| `harrow` | 藏青细引线：尾巴小圆点、实心小箭头 |
| `hcheck` / `hcross` | 红笔勾 / 红笔叉 |
| `marker` | 浅蓝平涂 |
| `squiggle` | 一行灰色的「正文」短条 |
| `sheet` | 剪下来的一块报纸：白、细灰边、顶上两道藏青线、淡投影 |
| `photo` | 白卡上的黑白新闻照（细黑框），下面红方块 + 图注 |

## 转场

| 名字 | 样子 | 什么时候用 |
|---|---|---|
| `paper`（默认） | 下一页像一张新报纸从右边盖上来（带一点倾斜和投影） | 大部分时候 |
| `dive` | 上一页往里冲、变淡，下一页从远处迎上来 | 从总览进到细节、换一个事件 |

## 字幕和人物小窗

- 字幕：白条 + 上面一道藏青粗线，黑字。
- 人物小窗：白边 + 细黑框，像报纸上的人物小照。

## 音效

逐字出来是打字机声（`typing`），卡片落下 `paper_drop`，圈和勾 `pencil`，结论章 `stamp`，贴剪报 `snip`（剪刀），转场 `page_flip`。
