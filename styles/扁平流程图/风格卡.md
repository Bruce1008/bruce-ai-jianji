# 扁平流程图

奶油色底上的扁平科普信息图：琥珀黄的色块和页眉带、特粗的近黑字、带一点厚度的彩色块。东西都是平的，只靠一层不模糊的错位投影显出前后；背景有慢慢转的浅灰钟面和飘着的扁平小几何。干净、明快、好懂。

**适合**：讲流程、讲步骤、讲「A 和 B 有什么不同」、工具教程、轻松的科普。
**不太适合**：严肃、高级感的内容（用黑底科技）；新闻评论（用复古报刊）。

灵感来自 [dashi-animationstyle](https://github.com/chuspeeism/dashi-animationstyle) 的「扁平流程图」风格；这里的代码和部件是重新写的，跑在 bruce-ai-jianji 的 Python 引擎上。

静帧：`静帧/横屏_标题页.jpg`、`静帧/横屏_照片页.jpg`、`静帧/横屏_数字页.jpg`、`静帧/竖屏.jpg`

## 配色

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 奶油 `CREAM` | `#fcf9ec` | 全屏底色 |
| 琥珀 `AMBER` | `#fbbf2f` | 页眉带、标题块、标签、结论块、圈、箭头 |
| 近黑 `INK` | `#1a1410` | 字 |
| 错位投影 `SHADOW` | `#efe3c2` | 所有块下面那层不模糊的影子 |
| 红 `RED`（`ACCENT`） | `#d41928` | 第一个重点词、叉 |
| 蓝 `BLUE`（`ACCENT2`） | `#2373ce` | 第二个重点词 |
| 绿 / 橙 / 金 | `#4f9d34` / `#ee8013` / `#d98e04` | 勾、彩色小块、纸屑 |
| 暖灰 `WARM` | `#7d7363` | 说明、图注 |

## 字体

思源黑体：正文 700、标题和重点词 900、字幕 800。数字、英文用 Montserrat 900 / 800。

## 部件长相（用法见 `styles/部件.md`）

| 部件 | 在这个风格里 |
|---|---|
| `paper(head=)` | 奶油底 + 两个慢慢转的钟面 + 飘着的小圆、三角、方块、加号；head 是顶上一条琥珀色带 |
| `title` | 琥珀色圆角块弹出来，块里的特粗黑字一个个蹦出来，上面一行暖灰英文 |
| `tag` | 琥珀小胶囊，从左边滑进来 |
| `write` | 一个字一个字淡入上浮 |
| `block_word` | 带厚度的红（或蓝）块白字，弹出来 |
| `number` | 特粗数字 + 琥珀错位影子，从 0 数上去 |
| `mark` | 琥珀色特粗问号 / 叹号，弹出来后轻轻晃 |
| `stamp` | 琥珀结果块 + 角上黑底对勾，弹出来时撒一把彩色纸屑 |
| `hunder` / `hcircle` / `harrow` | 圆头琥珀粗条 / 琥珀粗线圈 / 尾巴透明的琥珀弧形箭头 |
| `hcheck` / `hcross` | 绿色圆标白勾 / 红色圆标白叉 |
| `marker` | 淡琥珀色圆角底 |
| `sheet` | 白色圆角卡 + 琥珀色窗口标题条（右上三个小点） |
| `photo` | 白色圆角卡里的图，下面一行图注 |

## 转场

| 名字 | 样子 | 什么时候用 |
|---|---|---|
| `slide`（默认） | 整页往左滑走，下一页从右边接上来，像镜头往右移到下一站 | 同一条流程往下讲 |
| `circle` | 下一页从中间一个圆里撑开，圆边一圈琥珀 | 换一个话题、揭晓答案 |

## 字幕和人物小窗

- 字幕：白色圆角条 + 琥珀色错位影子，特粗近黑字。
- 人物小窗：白边 + 近黑细框。

## 音效

逐字出来 `blip`，卡片落下 `desk_tap`，弹出 `bubble`，圈和箭头 `swish`，结论 `bell`，大数字 `wood_knock`。偏轻快、有点「啵」的感觉。
