# 手绘笔记

米白纸上用墨蓝钢笔画线稿，只用一种橙色做强调。线是一笔一笔描出来的，字是一个一个写出来的，页边的铅笔小涂鸦画了又淡掉，整页像一本正在记的研究笔记。

**适合**：概念拆解、学习笔记、「我发现了什么」、工具教程、慢慢讲清楚一件事。
**不太适合**：数字和图表很多的财经内容（用华尔街财经）、强节奏快剪、需要很强科技感的发布会内容（用黑底科技）。

灵感来自 [dashi-animationstyle](https://github.com/chuspeeism/dashi-animationstyle) 的「手绘笔记」风格；这里的代码和部件是重新写的，跑在 bruce-ai-jianji 的 Python 引擎上。

静帧：`静帧/横屏_标题页.jpg`、`静帧/横屏_照片页.jpg`、`静帧/横屏_数字页.jpg`、`静帧/竖屏.jpg`

## 配色

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 纸 `PAPER` | `#f6f6ef` | 全屏底色 |
| 白纸 `SHEET` | `#fcfcf8` | 纸片、便签、照片白边、字幕纸条 |
| 墨蓝 `INK` | `#15192d` | 线稿、字、@标签底 |
| 铅笔灰 `PENCIL` / `PENCIL2` / `PENCIL3` | `#98999a` / `#b9baba` / `#d4d5d3` | 页边涂鸦、占位线、虚线 |
| 橙 `ORANGE` | `#f8711c` | 唯一的强调色：圈、勾、波浪下划线、印章、色块词 |
| 深橙 / 淡橙 `ORANGE_DK` / `ORANGE_LT` | `#a63d0a` / `#fde6d2` | 橡皮纸套的边 / 马克笔高亮、胶带 |

只用这一种橙。别加红、绿、亮蓝，别加发光、故障、粒子。通用颜色名：`T.ACCENT` = 橙，`T.ACCENT2` = 墨蓝，`T.MUTE` = 铅笔灰；要区分两个重点词时，一个用 `ACCENT` 橙色块，一个用 `color=T.ACCENT2` 墨蓝色块。

## 字体（全部开源可商用，第一次用时自动下载）

| kind | 字体 | 用在哪 |
|---|---|---|
| `hand` | 小赖（手写） | 正文、@标签、说明、字幕 |
| `round` | 站酷快乐体（圆粗） | 标题、印章、大号中文 |
| `en` / `num` | Nunito（圆头） | 英文、数字 |

小赖缺的字会自动用思源黑体补上。

## 部件（`T.` 开头，写在 scenes.py 的画面函数里）

所有风格通用的部件和用法见 `styles/部件.md`；下表是它们在手绘笔记里的样子，外加几个手绘笔记独有的（`hbox`、`hdash`、`lead`、`hatch`、`en`、`pen`，用了换风格时那几处要改）。

每个画面函数第一行先 `T.paper(c, t)` 铺纸。`t` 是当前时间，`t0` 是这个东西开始出现的时间（都用口播时间，从 words.txt 里取字的时间）。

| 部件 | 演什么 | 节奏 |
|---|---|---|
| `paper(c, t, head=None)` | 纸底 + 纸纹 + 慢慢漂的光影 + 页边铅笔涂鸦；head 是左上角一行手写小字 + 铅笔虚线 | 一直在动；画面很满时 `doodle=False` |
| `cam(c, t, t0)` | 整页慢推 1.00 → 1.04（with 包住内容，纸在外面） | 7 秒推完 |
| `title(c, 字, x, y, 字号, t, t0, sub_en='ENGLISH')` | 虚线框标题，上沿「※ ENGLISH ※」，框里颗粒圆粗字 | 0.7 秒 |
| `tag(c, '@标签', x, y, 字号, t, t0)` | 墨蓝小方块白字，从左往右刷出 | 0.25 秒 |
| `write(c, 句子, x, y, 字号, t, t0, pen_on=True)` | 逐字写出，笔尖跟着 | 每字约 0.11 秒（`cps=9`）；`write_d(句子)` 算总时长 |
| `squiggle(c, x, y, 宽, p)` | 铅笔灰的一段段连笔，像没写完的字 | 0.5 秒 |
| `hbox` `hline` `hdash` `lead` | 手绘框（转角出头）、线、虚线、带圆点的引线 | 0.3–0.7 秒 |
| `hcircle(c, cx, cy, rx, ry, p)` | 橙色一笔圈出来（绕 1.1 圈） | 0.5–0.6 秒 |
| `hunder(c, x0, x1, y, p)` | 橙色波浪下划线 | 0.4 秒 |
| `hcheck` / `hcross` | 橙色勾 / 叉 | 0.3 秒 |
| `harrow(c, x0, y0, x1, y1, p)` | 手绘弯箭头 | 0.5 秒 |
| `hatch(c, x, y, w, h, p)` | 斜排线（暗部、填充） | 0.4 秒 |
| `marker(c, x0, x1, y, 高, p)` | 淡橙马克笔高亮（先画，字写在上面） | 0.45 秒 |
| `block_word(c, 词, x, y, 字号, t, t0)` | 实心色块白字（重点词） | 弹出 0.35 秒 |
| `stamp(c, 字, x, y, 字号, t, t0)` | 橙色橡皮章砸下来 + 震一下 | 0.22 秒 + 0.2 秒 |
| `number(c, '10', '亿美元', x, y, 字号, t, t0)` | 圆头大数字 + 圆粗单位，弹出来、从 0 数上去；`a=0` 只量宽度 | 0.35 秒 |
| `mark(c, '？', x, y, 字号, t, t0)` | 橙色圆粗大号标点，弹出来 | 0.35 秒 |
| `sheet(c, x, y, w, h, t, t0, layers=2)` | 白纸片 / 便签，叠几层，顶上胶带 | 落下 0.45 秒 |
| `photo(c, 图, x, y, w, h, t, t0, caption='来源')` | 贴在纸上的照片：白边、胶带、落定后框里慢推 | 0.5 秒 |
| `clip_img(S, key, 视频, 起点秒, t, w, h)` | 视频素材的当前帧，交给 `photo` 显示 | |
| `en(c, 'AI', x, y, 字号)` | 圆头英文，错开一层描边 | |
| `pen(c, x, y, t)` / `shake(t, t0)` | 笔尖 / 盖章震动 | |

`p` 是画到哪（0..1），一般写成 `T.prog(t, t0, 秒数)`。同一页里每个部件给不同的 `seed`，线条形状才不会一样。

## 版式

- **横屏**：左上角是人物小窗（`layout.PIP_SAFE` 那块别放重点），内容从小窗右边开始排；字幕在底部 y≈985，内容别低于 y 920。
- **竖屏**：内容放在 y 120–1330，字幕在 y 1415；两边各留 60 以上（抖音会裁边）。
- 常用排法：左照片右便签、上标题下要点、中间一个大数字加圈和印章。一页最多 3 组东西，别塞满。

## 动效和节奏

- 跟着口播走：关键词说出来前 0.05–0.1 秒开始画，说完这一句时这一页刚好画完。
- 一页里东西按顺序出来：标题 → 标签 → 逐字写 → 圈 / 勾 / 印章（最后一下砸在结论上）。
- 停住讲的时候也要有东西在动：页边涂鸦和光影一直在动，`cam` 慢推，照片在框里慢推。超过 2.5 秒画面几乎不变，`checks.py` 会报出来。

## 转场

| 名字 | 样子 | 什么时候用 |
|---|---|---|
| `scroll`（默认） | 整张纸往上滑，下一段接上来 | 同一章节里往下讲 |
| `page` | 右下角掀起来翻页 | 换一个小话题 |
| `erase` | 橡皮擦来回擦掉，露出下一页 | 「但是」「其实不是」：推翻上一页 |
| `zoom`（内置） | 推近穿过去 | 从总览进到细节 |

一条片子里轮着用，同一种别连用三次以上。转场音效自动配：翻页声、纸滑声、铅笔擦声。

## 字幕和人物小窗

- 字幕：一条白纸条（四角略歪、浅灰边、淡阴影）上的墨蓝手写字，压在任何画面上都看得清。
- 人物小窗：白边 + 手绘墨蓝轮廓 + 顶上一段淡橙胶带，放大成人物全屏时边框淡出。

## 音效

cues.py 里写 `@write` 这类动作名（见 `styles/部件.md`），这个风格配成：逐字写 `pen`，纸片落下 `paper_drop`，弹出 `pop`，圈和下划线 `marker`，盖章 `stamp`，胶带 `tape`，勾 `pen`，转场翻页声、纸滑声。都是轻的，比人声低 10 dB 以上。
