# 风格部件（5 个风格通用）

每个风格的 `theme.py` 都提供下面这套部件，**名字、参数、返回值完全一样，只是长相不同**。scenes.py 只用这些部件写，换风格就不用改 scenes.py：

- 正式换：在 `_工程` 里 `python style_preview.py <风格> --use`（换掉 theme.py）。
- 只想试看：命令前面加 `BAJ_STYLE=<风格>`（Windows 先 `set BAJ_STYLE=<风格>`），这一次就用那个风格出图，工程里的 theme.py 不动。比如：
  ```
  BAJ_STYLE=黑底科技 python render.py video 预览_黑底科技.mp4 0 15
  BAJ_STYLE=黑底科技 python mix_master.py ../成片/开头15秒_黑底科技.mp4 --video 预览_黑底科技.mp4
  ```

`t` = 当前时间，`t0` = 这个东西开始出现的时间（都是口播时间，从 words.txt 取）。`p` = 画到哪（0..1），一般写 `T.prog(t, t0, 秒数)`。`seed` 让同一页里几个部件的随机形状不一样。

## 底和镜头

| 部件 | 做什么 |
|---|---|
| `T.paper(c, t, head=None)` | 每个画面函数第一行：铺这个风格的底。`head='第 4 步 · 找素材'` 在顶上加一行页眉（每个风格样子不同：便签字、琥珀色带、金色小字、报头、金色小标签） |
| `with T.cam(c, t, t0, amt=0.04, dur=7):` | 整页慢推，内容写在 with 里面（底在外面） |

## 字

| 部件 | 返回 | 做什么 |
|---|---|---|
| `T.title(c, 字, x, y, 字号, t, t0, sub_en='ENGLISH')` | — | 大标题（x 是中心），上面一行英文小字 |
| `T.tag(c, '@标签', x, y, 字号, t, t0)` | 宽度 | 小标签（x 是左边） |
| `T.write(c, 句子, x, y, 字号, t, t0, cps=9, color=None, kind='hand', align='l')` | (出到的 x, y) | 一个字一个字出来；`T.write_d(句子, cps)` 算出完要几秒 |
| `T.block_word(c, 词, x, y, 字号, t, t0, color=None, align='c')` | 宽度 | 重点词色块。默认 `T.ACCENT`；第二个重点用 `color=T.ACCENT2` |
| `T.number(c, '10', '亿美元', x, y, 字号, t, t0, align='c')` | 总宽 | 大数字 + 单位，从 0 数上去。`a=0` 只量宽度不画（先量宽再画高亮、圈） |
| `T.mark(c, '？', x, y, 字号, t, t0)` | — | 大号标点（？！） |
| `T.stamp(c, 字, cx, cy, 字号, t, t0)` | — | 结论章 / 结论牌，砸下来 |

## 线和标记

| 部件 | 做什么 |
|---|---|
| `T.hunder(c, x0, x1, y, p)` | 下划线 |
| `T.hcircle(c, cx, cy, rx, ry, p)` | 圈出来 |
| `T.harrow(c, x0, y0, x1, y1, p, curve=0.15)` | 弧形箭头（curve 正负决定往哪边弯） |
| `T.hcheck(c, x, y, 大小, p)` / `T.hcross(...)` | 勾 / 叉 |
| `T.marker(c, x0, x1, y, 高, p)` | 高亮（先画，字写在上面） |
| `T.squiggle(c, x, y, 宽, p)` | 占位的「字」（还没讲到的内容） |
| `T.hline(c, x0, y0, x1, y1, p)` | 引线 |

## 卡片、照片

| 部件 | 做什么 |
|---|---|
| `T.sheet(c, x, y, w, h, t, t0, layers=1)` | 卡片（便签 / 白卡 / 玻璃卡 / 剪报），`layers=2` 后面多叠一张 |
| `T.photo(c, 图, x, y, w, h, t, t0, caption='来源')` | 照片；图可以是文件路径或 `clip_img` 取的视频帧 |
| `T.clip_img(S, key, 视频, 起点秒, t, w, h)` | 视频素材的当前帧，交给 `photo` |

## 颜色和字体

- 颜色：`T.INK`（正文）、`T.ACCENT`（第一强调色）、`T.ACCENT2`（第二强调色）、`T.MUTE`（灰、次要）。scenes.py 里不要写死色值。
- 字体 kind（给 `text`、`text_w`、`write` 用）：`hand` 正文、`round` 标题 / 大字、`num` 数字、`en` 英文、`sub` 字幕。量宽度用同一个 kind：`text_w('先出开头', 64, 'hand')`。

## 音效（cues.py）

写动作名，不写具体声音，每个风格自己配：
```python
cue(t, '@write')   # 逐字出来
cue(t, '@drop')    # 卡片、照片落下来
cue(t, '@pop')     # 重点词、标签弹出来
cue(t, '@mark')    # 圈、下划线、箭头、大号标点
cue(t, '@stamp')   # 结论章
cue(t, '@stick')   # 贴上去（手绘的胶带、报刊的剪刀；有的风格不出声）
cue(t, '@tick')    # 勾、叉
cue(t, '@number')  # 大数字
cue(t, '@whoosh')  # 大东西飞进来
```
可以加音量：`cue(t, '@drop', -3)`。某个风格不出声的动作会返回 None，cues.py 最后要过滤掉：`CUES = [x for x in CUES if x]`。

## 转场

TIMELINE 里不写 `tr` 就用这个风格的默认转场。各风格自己的转场：

| 风格 | 默认 | 还有 |
|---|---|---|
| 手绘笔记 | `scroll` | `page`、`erase` |
| 扁平流程图 | `slide` | `circle` |
| 黑底科技 | `dissolve` | `glow` |
| 复古报刊 | `paper` | `dive` |
| 华尔街财经 | `whip` | — |

内置转场 `zoom`、`push`、`fade`、`flash`、`cut` 哪个风格都能用。写了某个风格专有的转场名再换风格，换过去的风格没有这个名字时自动用它自己的默认转场，不会出错。

## 风格自己独有的部件

有的风格多几个自己的部件（手绘笔记的 `hbox`、`hatch`、`tape`、`lead`、`en`、`doodles`）。用了它们，换风格时那几处要改。想随时能换风格，scenes.py 只用上面的通用部件。

## 做一个新风格

复制一个最接近的 `styles/<风格>/theme.py` 到新文件夹，改配色、字体、每个部件的画法，**名字、参数、返回值不改**。再写 `风格卡.md`，`python style_preview.py <新风格>` 出静帧看（示例页面在 `styles/示例.py`，所有风格共用）。底层小工具（渐变、逐字出现、颗粒、暗角、发光）在 `scripts/stylekit.py`。
