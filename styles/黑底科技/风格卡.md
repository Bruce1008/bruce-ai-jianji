# 黑底科技

近黑的底，画面一角一团暖色的光，飘着细细的金色星尘和胶片颗粒。字是宋体，标题和数字是金色渐变字，一个字一个字由虚到实浮出来；线都是发光的细金线，画的时候笔尖带一颗亮点；卡片是深色玻璃 + 四角金色括号；结论是一枚红色印章砸下来。安静、高级、有分量。

**适合**：AI 新闻、发布会、行业大事、「这件事为什么重要」、有点严肃的深度内容。
**不太适合**：轻松搞笑、步骤很多的教程（用扁平流程图或手绘笔记）。

灵感来自 [dashi-animationstyle](https://github.com/chuspeeism/dashi-animationstyle) 的「黑底科技」风格；这里的代码和部件是重新写的，跑在 bruce-ai-jianji 的 Python 引擎上。

静帧：`静帧/横屏_标题页.jpg`、`静帧/横屏_照片页.jpg`、`静帧/横屏_数字页.jpg`、`静帧/竖屏.jpg`

## 配色

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 底 `BG0` → `BG1` | `#0b0f15` → `#05070b` | 全屏底色（上浅下深） |
| 暖光 `WARMG` | `#3e3220` | 画面一角那团光 |
| 金 `GOLD`（`ACCENT2`） | `#e5cf95` | 线、括号、小字、标签字、第二个重点词（金币块） |
| 金字渐变 `GOLD_G` | `#faefcc` → `#ddc994` → `#ae915c` → `#8c6330` | 标题、数字、大号标点 |
| 正文 `TXT` | `#e2dfd3` | 正文、字幕 |
| 玻璃 `GLASS` / 边 `GLASS_B` | `#1a1713` / `#373334` | 卡片、标签底 |
| 印章红 `SEAL`（`ACCENT`） | `#b1312a` | 第一个重点词、结论章 |

只用金和一点印章红。别加亮蓝、霓虹、故障效果。

## 字体

思源宋体：正文 600、标题和大字 900、字幕 700；数字也用思源宋体 900。英文小字用 Playfair Display。

## 部件长相（用法见 `styles/部件.md`）

| 部件 | 在这个风格里 |
|---|---|
| `paper(head=)` | 近黑渐变 + 慢慢漂的暖光 + 上升闪烁的金色星尘 + 颗粒 + 暗角；head 是顶上一行加宽字距的金色小字，后面拖一条渐隐的金线 |
| `title` | 金色渐变宋体逐字由虚到实，背后一团光，下面一条从中间往两边拉开的细金线 + 小菱形 |
| `tag` | 深色玻璃胶囊 + 细金边 + 金字，由虚到实滑进来 |
| `write` | 浅色宋体，一个字一个字由虚到实 |
| `block_word` | 印章红块浅字（`ACCENT`）或金币块深字（`ACCENT2`），由虚到实落下 |
| `number` | 金色渐变大数字，由虚到实、从 0 数上去，背后一团光 |
| `mark` | 金色渐变问号 / 叹号，浮出来后轻轻上下浮 |
| `stamp` | 红色印章砸下来、震一下，落定时一圈金色光环散开 |
| `hunder` / `hcircle` / `harrow` | 发光细金线，笔尖带亮点；箭头是空心的 |
| `hcheck` / `hcross` | 细金圈 + 金勾 / 细红圈 + 红叉 |
| `marker` | 一条暖金色光带，底边一条细金线 |
| `sheet` | 深色玻璃卡 + 顶上一道金色高光 + 四角金括号 |
| `photo` | 细金框里的图，四角金括号，下面一行加宽字距的小字 |

## 转场

| 名字 | 样子 | 什么时候用 |
|---|---|---|
| `dissolve`（默认） | 上一页虚掉、轻轻放大着淡出，下一页由虚到实淡入 | 大部分时候 |
| `glow` | 画面中间亮起一团暖金色的光把上一页吞掉，光退下去露出下一页 | 揭晓、转折、新的一章 |

## 字幕和人物小窗

- 字幕：两头淡出的半透明深色条，浅色宋体字。
- 人物小窗：细金边 + 四角金括号。

## 音效

逐字出来 `low_swish`（很轻），卡片落下 `deep_whoosh`，弹出 `sparkle`，结论章 `boom`，大数字 `swell`，勾 `ding`。低沉、有空间感。
