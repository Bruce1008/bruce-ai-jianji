# 三列脚本表模板

画面要求多的时候用。把这张表和口播视频一起发给 AI Agent，AI Agent 会照「画面」一列做分镜；「画面」空着的句子，AI Agent 自己设计。

## 怎么填

| 列 | 填什么 | 注意 |
| --- | --- | --- |
| 口播词 | 一句一行，从口播文档原样复制 | 和你录的内容一字不差，AI Agent 靠这一列对时间 |
| 画面 | 这一句观众应该看到什么 | 只写看到什么，不用写动画怎么实现；不填就交给 AI Agent |
| 参考资料 | 这一句要用的素材文件名、链接或参考图 | 文件都放在同一个素材文件夹里；没有就空着 |

「画面」一列常用的写法：人物全屏、人物小窗加全屏动画、全屏显示提示词、播放某段录屏、几个词依次出现并亮其中一个、数字对比。

## 发给 AI Agent 的提示词

```
画面按附件这张脚本表做：「画面」一列写了的按要求做，空着的你来设计；「参考资料」里的文件在 <素材文件夹路径>。口播视频在 <口播视频路径>。
```
